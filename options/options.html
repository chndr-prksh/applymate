ApplyMate

Fills the application form in front of you. Open a job application and press the Fill button (or Alt+Shift+F). You review and submit.

Claude API key

Used for custom questions and resume import. Stored only in this browser. Standard fields (name, email, links, work authorization) fill without it.

Install Ollama from ollama.com, run ollama pull qwen2.5:3b, then start it so the extension may use it: quit the Ollama app and run OLLAMA_ORIGINS="chrome-extension://*" ollama serve in Terminal. The resume is still written by Claude, so keep your API key above.

Resume

The PDF is attached to resume upload fields. Importing reads it once with Claude and fills in the profile below.

Advanced: edit the profile as JSON

Applications

Every job you filled or applied to, with the exact resume that was attached. Opening a job you already applied to shows a warning instead of filling; choose “Apply again” there to override, or remove it here.

Prompt log

The last 40 requests sent to Claude and what came back, newest first: the exact instructions, your data as sent, and the response. Use it to review and tune the prompts.

Saved answers

Answers you typed or picked yourself on a form are saved here automatically. The same question is filled from here next time, and they are given to the AI as examples for differently worded versions. Demographic answers are saved only when you press “Save answers”, and never go to the AI.
